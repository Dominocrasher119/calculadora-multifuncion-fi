# Calculadora multifunción

Proyecto de Fundamentos de Ingeniería que reúne cálculos aritméticos, una media ponderada, conversiones de bases y unidades informáticas, potencias de 2 y logaritmos en base 2.

## Requisitos y ejecución

Se necesita Python 3. No se utilizan librerías externas. Para iniciar el programa, ejecuta desde esta carpeta:

```bash
python main.py
```

## Funcionalidades

1. Operaciones aritméticas: suma, resta, multiplicación y división.
2. Cálculo de media ponderada.
3. Conversión entre bases binaria, octal, decimal y hexadecimal.
4. Conversión entre KiB, MiB y GiB con equivalencias de 1024.
5. Cálculo de potencias de 2.
6. Logaritmos en base 2.

## Organización

- `main.py`: punto de entrada.
- `menu.py`: menú, navegación y entrada interactiva.
- `utils.py`: validación de datos introducidos por teclado.
- `operaciones.py`: operaciones aritméticas.
- `notas.py`: cálculo de media ponderada.
- `calculos.py`: potencias de 2 y logaritmos en base 2.
- `conversiones.py`: funciones de conversión de Roger.
- `calculadora.ipynb`: notebook recibido con el trabajo de exploración de conversiones; revisar y completar como notebook definitivo de la entrega.
